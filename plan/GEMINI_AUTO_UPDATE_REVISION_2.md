# Codex qəbul yoxlaması: CHANGES_REQUESTED

Əvvəlki düzəlişləri qoru, aşağıdakı qalıqları vahid paketdə tamamla. Build/push/deploy/install və canlı xidmətlərə toxunma.

1. P1 — LKG qorunması: `stage_native_update_bundle` PROBATION zamanı növbəti yenilənməni staging etməməlidir. Bu vaxt inactive slot last_known_good_slot ola bilər; onu silmək rollback nüsxəsini məhv edir. test_07 hazırda commit etmədən ikinci staging-i uğur sayır. PROBATION/STAGING/PENDING_ACTIVATION zamanı təkrar staging-i blokla; yalnız təsdiqlənmiş vəziyyətdə növbəti update. Real host guard-dan əlavə ortaq engine sərhədini də qoru. Diskdə LKG hash-lərinin dəyişmədiyini test et.
2. P1 — `clean_lingering_slot_processes`: canonical target `\\?\D:\...`, QueryFullProcessImageName isə adətən `D:\...` qaytarır; müqayisə eyni formata gətirilməyib. `starts_with` komponent sərhədi yoxlamır və bütün executable-ları öldürür. Qorunan slot kökünü doğrula; yalnız dəqiq təsdiqlənmiş WinKey executable yollarını idarə et, əvvəl nəzakətli çıxış/handoff istə; terminate/wait nəticələrini yoxla. Aktiv/LKG worker-i öldürmə. Qonşu `slot_a_other` prosesinin toxunulmazlığını və həqiqi kilidli disposable desktop ilə A→B→COMMITTED→A axınını test et. Canlı quraşdırılmış proseslərə toxunma.
3. P1 — Handover: `WaitForSingleObject` nəticəsi udulur. Timeout/access denied ayrıca nəticə versin; köhnə prosesin bitməsi təsdiqlənmədən uğurlu handoff elan etmə. GUI parser rəqəmli PID-ni ayrıca arqument kimi qəbul etmədiyi üçün `--relaunch-handover 123` GUI yönləndirməsini false edir; `starts_with` əvəzinə dəqiq parser qur. `--tray` həqiqətən minimize etsin. Test yalnız --check yox, disposable proseslə singleton/handoff davranışını da yoxlasın.
4. P2 — Build rollback atomik deyil: sync_project_metadata try blokundan əvvəl faylları dəyişir, istisnaları udur; Cargo.lock ehtiyatlanmır. Payload binarları yeniləndikdən sonra yalnız köhnə manifestin bərpası pre_signed_slot_a-nı uyğunsuz qoya bilər. Bütün release staging-i müvəqqəti qovluqda qur; yalnız tamamlandıqdan sonra publish göstəricisini dəyiş. Metadata/lock bərpasını səhvləri gizlətmədən yoxla. Hər build mərhələsində fault injection və əvvəlki release-in hash/imza bütövlüyünü test et.
5. P2 — SETUP_REQUIRED yalnız JS mətnidir: native status/journal yolunda həmin vəziyyət yoxdur. E_HOST_UPGRADE_REQUIRED nəticəsini davamlı statusa bağla və get_update_status vasitəsilə göstər. Eyni protokol sabitini istifadə et, engine-də hardcoded 1 saxlamadan yanlış tipli protokol sahələrini rədd et. Əvvəlki host-ların bu yeni yoxlamanı bilmədiyini hesabatda açıq yaz; geriyə uyğunluq zəmanəti vermə.
6. Test dürüstlüyü: test_native_gateway_e2e_update.py populate_slot hələ `b'MZ'+zeros` faylları yaradır; bu real PE/worker icrası deyil. Real download/staging coverage-ni saxla, hesabatı düzəlt. Ayrı disposable real executable sınağı ilə file-lock/handoff sübutu ver. --record-crash çağırışı həqiqi worker crash/supervisor restart sübutu deyil. Test açarı production env ilə əvəz oluna bilməsin; release və debug sərhədini yoxla.
7. Mərhələ telemetriyası hələ tam deyil: release id, əvvəlki/yeni versiya, activate/probation/commit/rollback müddət və xətalarını eyni update correlation ilə bağla; yalnız download/stage hadisələrini bütün tələbin icrası kimi təqdim etmə.

Codex bu baxışda Node UI testini işə saldı: PASS. Python syntax yoxlaması xəta çıxarmadı. Rust/SCM və tam update bu baxışda icra edilməyib. Yeni hesabatda faktiki test əmrləri, ayrıca xam loglar, binary yolu/hash-i və NOT_TESTED sərhədlərini göstər. Bütün qalıqları tamamlayıb Codex qəbulu üçün dayan.
