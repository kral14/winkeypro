# Son WebSocket boşluqları — vahid batch

`plan/audit/WEBSOCKET_REVISION_2_ACCEPTANCE.md`, GEMINI_RULES və ilkin WS müqaviləsini oxu. R3-01–R3-06-nın hamısını bir batch-də düzəlt; arada dayanma. Codex-in mark_command_delivered SQL düzəlişini və Docker allowlist-ni qoru. Fiziki PIN/lock/fokus axınına toxunma.

1. Faktiki VM Origin-i və konfiqurasiya edilən gələcək HTTPS origin-ləri qəbul et; LAN ünvanını ipaddress ilə doğrula. Etibarsız scheme/host/suffix/port origin-ləri rədd et. Proxy/public URL konfiqurasiyasını sənədləşdir. `scripts/codex_ws_revision2_audit.py`-nin hər iki testi keçməlidir; testi zəiflətmə.
2. Native WS bağlantısını həqiqətən bounded və ləğv edilən et. Detached blocking connect thread timeout həlli deyil. DNS/TCP/TLS/upgrade/auth üçün limit; stop/pause zamanı resursların bağlanması; ardıcıl səssiz-server sınaqlarında thread/socket sayının sabitliyini sübut et.
3. Native qəbul→queue→execution→result davamlı state maşınını tamamla. Queue-dan əvvəl durable inbox, execution-dan əvvəl yoxlanmış journal commit; yazı/oxu/parse/replace xətasında input başlamasın. Nəticə saxlanmadan journal silinməsin və ACK-a etibar edilməsin. Unfinished ID-lər dedup compaction ilə itirilməsin. SUPERSEDED üçün eyni qayda. Disposable child crash və disk fault testlərini müxtəlif kəsilmə nöqtələrində icra et; həqiqi input yox, mock istifadə et.
4. Server DB claim və socket ownership protokolunu tamamla. Enqueue socket delivery deyil. Writer/disconnect/claim-expiry/restart zamanı hər command terminal və ya explicit indeterminate vəziyyətə gəlsin; sonsuz delivered qalmasın. Köhnə attempt-in result-u yeni attempt-ə aid olmasın. Fiziki side-effect-in exactly-once olmasını əsassız iddia etmə. Deterministik testlər: socket writer queue-dan əvvəl/sonra crash, result-before-delivered, stale result, reconnect, expired lease, agent restart. SQLite və disposable PostgreSQL-də icra et.
5. Yük testini faktiki Linux gateway Docker konteyneri + disposable PostgreSQL ilə et. Eyni backend/workload üzrə müqayisə apar; əvvəlki Windows+SQLite rəqəmlərini ayrıca tarixi göstərici kimi saxla. 100 agent/100 telefon, idle HTTP poll, faza timing, DB wait, event-loop lag, memory/thread/socket sayı və test mühitini dəqiq yaz. Server timestamp ilə client timestamp fərqini saat sinxronizasiya qeydi olmadan saf network latency sayma. Physical unlock NOT_TESTED qalsın.

Hesabat: `plan/reports/WEBSOCKET_REVISION_3_REPORT.md`; xam sübutlar `plan/reports/websocket/revision3/`. Hər düzəlişə real regression/fault sübutu ver, model testi ilə crash testini əvəz etmə. Mövcud suite-ləri də uyğun regression üçün işlətdikdən sonra READY_FOR_AUDIT bildir. Public push/deploy, installer/service əməliyyatı, geniş taskkill və fiziki input etmə. Real secret oxuma/loglama. Açıq risk varsa gizlətmə.
