# WebSocket — qalan işləri bir batch-də tamamla

Əvvəl `plan/GEMINI_RULES.md`, `docs/PROJECT_LAYOUT.md`, `plan/audit/WEBSOCKET_REVISION_1_ACCEPTANCE.md` və ilkin `plan/GEMINI_WEBSOCKET_BATCH.md` müqaviləsini oxu. Aralıq audit gözləmədən R2-01–R2-05-in hamısını tamamla. İşləyən unlock/fokus/PIN/ACL axınını dəyişmə.

1. HTTP, WS, reconnect və paralel agentlər üçün ortaq DB claim/lease protokolu qur. Claim commit-dən əvvəl frame göndərmə. Köhnə socket/lease nəticələrini müəyyən et; uğursuz göndərişin bərpasını və terminal retry-ni saxla. Enqueue→push aralığını idarə olunan gate ilə saxlayaraq HTTP poll yarışı, paralel reconnect və proses restart sınaqlarını real disposable SQLite və PostgreSQL-də icra et. Unikal mock execution və bütün command-ların terminal nəticəsini say.
2. Native inbox/outbox-u qəza sonrası bərpa edilən et: Windows atomik durable replace (hədəfi silmə), write/sync/replace xətasında məlumatı qoruma, korlanmanı boş uğur kimi qəbul etməmə, icradan əvvəl handled mark ilə RAM queue itkisinin aradan qaldırılması. Diskə yazılmayan nəticəni uğurlu davamlı nəticə sayma. SUPERSEDED nəticələri reconnect tələb etmədən ACK-a qədər çatdır. Disposable child-process crash/fault testləri: write/sync/replace, enqueue→execution, execution→save, send→ACK. Qeyri-müəyyən fiziki icranı avtomatik təkrarlama; recovery vəziyyətini açıq bildir.
3. Həqiqi DNS/TCP/TLS/HTTP upgrade/auth əməliyyatlarını deadline ilə məhdudlaşdır. Ayrı socket precheck kifayət deyil. Səssiz TCP/upgrade serveri və unreachable endpoint ilə timeout və STOP/pause müddətini ölç. Token, frame və URL query-ni loga çıxarma.
4. Mobil browser Origin siyasətini LAN/bulud müqaviləsinə uyğun qur; native agent üçün Origin olmayan autentifikasiyalı bağlantını nəzərə al. Handshake/message rate, real transport frame limiti, bounded writer/queue timeout-larını tətbiq et. Wrong-Origin, oversized frame, flood, slow-consumer və revoke testlərini əlavə et. Əvvəlki mobil telemetry id/ACK/outbox müqaviləsini pozma.
5. Linux Docker + təcrid PostgreSQL-də ən azı 100 agent/100 telefon yük sınağı apar. Enqueue commit, claim, socket dispatch, mock execute, result commit, phone ACK fazalarını correlation ID ilə ölç; event-loop lag və DB wait-i göstər. Revision1 p95 ilə eyni workload müqayisəsi ver. Ölçülməyən səbəbi fakt kimi yazma. Fiziki unlock testini ayrıca NOT_TESTED saxla.
6. Codex-in Docker allowlist düzəlişini qoru. Runtime import/health/authenticated WS və FAKE secret-canary exclusion testlərini avtomatlaşdır; real signing key-ni açma/loglama. Əvvəlki geniş COPY ilə yaranmış image-lər paylaşılmamalıdır. İstehsal sirrlərinə toxunmadan təhlükəsiz yoxlama qaydasını sənədləşdir.

Yekunda `plan/reports/WEBSOCKET_REVISION_2_REPORT.md` yaz; xam log, exit code, ölçülər və fault injection-ları `plan/reports/websocket/revision2/`-də saxla. Hər bənd üçün kod, faktiki sübut və qalan məhdudiyyət göstər. Mövcud testləri zəiflətmə; source-string/model testi real crash/transport testinin əvəzi deyil. Test zamanı geniş taskkill/service stop, installer quraşdırması və fiziki LOCK/PIN input etmə. Push/deploy etmə. Bütün batch-dən sonra READY_FOR_AUDIT bildir.
