# Runtime tamamlanması — hesabatla kod fərqi

Əsas bütün-qalıqlar tapşırığı qüvvədədir. Yeni native staging və ACK dequeue faydalıdır, lakin actual auto-update və durable installer retry tamamlanmayıb.

1. **Native staging yalnız test CLI-dən çağırılır.** main.rs-də stage_native_update_bundle yeganə çağırışı --test-native-update-stage-dir. Real host/worker timer və HTTP download/poll yoxdur. Runtime signed update fetch -> validated inactive slot -> actual activation/restart -> child health -> commit/rollback bütöv bağlansın. Tək staging funksiyasını auto-update adlandırma. Testdə timer/runtime trigger yeni versiyanı endirib actual version/PID switch sübut etsin; dəyişməyən/downgrade/invalid-target/offline halları da yoxlansın.
2. **Installer outbox durable-before-send deyil.** Write-WinKeyDiagnosticEvent yeni event-i yaddaşa əlavə edir, bütün HTTP göndərişlərini edir, yalnız sonda diski yazır. Crash/network wait zamanı event itə bilər. Əvvəl durable append/atomic replace+flush, sonra send, sonra ACK dequeue olsun. Hazır kod yalnız 5000 record count yoxlayır, 20MB byte bound yoxdur. Processlərarası lock, fixed run ID, corruption quarantine, bounded total send budget və ayrı restart replay sender tələb olunur. 5000*3s installer-i saxlamaq olmaz. DryRun sistemdə default ProgramData yaratmamalıdır.
3. **Test hesabatı səhvdir.** unittest discover yalnız unittest TestCase-ləri avtomatik işlədir; main()/standalone script-ləri icra etmir, scripts/ auditlərini də tests/ discover tapmır. '31 suite ALL_PASS' üçün hər suite exact command/exit/raw log ilə run_all runner-ə əlavə et. unittest-in faktiki test ID/count/skip siyahısını ayrıca saxla. XSS testi Python escape təqlidini yoxlayır, actual browser DOM regression deyil: kateqoriyanı düzəlt və ya real JS/DOM testi yaz.
4. **Dürüst qalıqlar.** Owner hesabı private admin/Sites deploy, HTTPS WAN, clean VM və fiziki unlock PARTIAL/NOT_TESTED-dir. Auto-update runtime tamamlanmayıbsa NOT_IMPLEMENTED/PARTIAL göstər. Byte bound və automatic replay kodu yoxdursa IMPLEMENTED yazma. Stage functions ilə real tətbiq entrypoint matrisi təqdim et.

Bütün mümkün kod/build/test işlərini toplu tamamla, Codex XSS/helper/IPC qorunmaları qalsın. Yeni immutable revision ZIP/hash və raw logs ver. Şəxsi hostda lock/service install/reboot yoxdur; production publish/audience/key alışları ayrıca owner sərhədidir.
