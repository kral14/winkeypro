# Admin paneli və OTA telemetriyası üzrə yekun qəbul

`plan/GEMINI_ADMIN_PANEL_EXPANSION.md` sənədindəki işi mövcud kod üzərində tamamla. Aşağıdakı işləri bir paketdə təhvil ver.

1. **Növbə etibarlılığı.** Codex-in mutex alınmadan yazmağı bloklayan düzəlişini qoru. İki ayrı OS prosesi və sinxronizasiya nöqtəsi ilə təsdiqlənmiş qeydlərin çıxarılması və yeni qeydin yazılması toqquşmasını yoxla. Mutex timeout zamanı faylın dəyişmədiyini, yenidən cəhdin məhdud olduğunu və saxlanmayan hadisənin xətasının göründüyünü yoxla. HTTP gecikməsi əsas axını saxlamasın. Restart və bağlantı bərpasından sonra saxlanmış hadisələr yeni hadisə gözləmədən çatsın. Server qeydi saxlayıb cavabı itirdikdə eyni event ID ilə təkrar göndərişi faktiki server və DB-də yoxla. Növbə boşalmalı və tarixçədə bir qeyd qalmalıdır.
2. **Real OTA sübutu.** Təcrid olunmuş Windows mühitində mövcud imzalı iki versiya ilə production update yolunu işə sal. Həqiqi worker keçidi `UPDATE_COMMIT_DONE` yaratmalı və hadisə WinKey telemetriya kanalı ilə cihazın admin tarixçəsində avtomatik görünməlidir. Versiyanı, cihazı, mərhələni və ölçülən müddəti tutuşdur. Python POST, əl ilə SQL və `diagnostics::stage()` çağırışı real OTA sübutu sayılmır. Uyğun paket və ya təcrid olunmuş Windows mühiti çatışmırsa, həmin sınağı `NOT_TESTED` göstər və çatışmayan şərti yaz.
3. **Panelin qəbulu.** Sintetik məlumatla lokal önizləməni işə sal və təhvil zamanı açılan link ver. Brauzerdə bölmələr, axtarış, filtr, səhifələmə, cihaz detalı, komanda zaman xətti, yenilənmə tarixçəsi, export və WS reconnect yoxlanılsın. Admin icazəsi olmayan API və WS sorğuları rədd edilməlidir. Demo məlumatı və faktiki OTA nəticəsi ayrı göstərilsin. Screenshot tələb olunmur.

`plan/reports/ADMIN_PANEL_FINAL_ACCEPTANCE_REPORT.md` faylında dəyişiklikləri, test əmrlərini, nəticələri və açıq qalan halları qeyd et. Əvvəlki uğurlu testləri yalnız yeni dəyişikliklərin təsir etdiyi hissələrdə təkrarla. Canlı push, deploy, paket yayımı və aktiv Windows xidmətinə müdaxilə bu tapşırığın əhatəsindən kənardır. Yekun hesabatı Codex qəbuluna təqdim et.
