# Köhnə mənbələr — aktiv məhsul deyil

- `rustdesk/`: ayrıca upstream RustDesk layihəsi; WinKey build-ə daxil deyil.
- `remote_agent/`: əvvəlki Python GUI prototipi. Hazır Tauri məhsulu bunu çağırmır.
- `web_remote/`: əvvəlki Sites/Vinext frontend-i. VM-in aktiv mobil/admin səhifələri
  `deploy/gateway_production_server.py` daxilindədir.
- `launchers/`: köhnə prototip başlatma/silmə skriptləri; gündəlik istifadə üçün deyil.

Gündəlik girişlər: kökdə `run.py`, `build.py`; cari installer `dist/WinKeySetup.exe`.
Köhnə istinadlar tarixi plan/hesabatlarda qala bilər; yeni işdə cari yolları istifadə edin.
